**Конвертер файлов Supercell (`.sc`) в проект Adobe Animate (`.fla`) на Java.**

![Демонстрация работы](../media/preview.gif)

---

## Описание

Программа читает игровые `.sc`-файлы (используемые в играх Supercell, например, Clash of Clans или Brawl Stars) и преобразует их в формат **XFL**, который затем упаковывается в `.fla`-архив. 

---

## Требования к системе

- **Java 17** или выше.
- **PVRTexToolCLI** – утилита от Imagination Technologies для преобразования сжатых KTX-текстур в PNG.  
- Положите исполняемый файл в ту же папку, что и `sc2fla.jar`, или укажите путь через переменную окружения `PVRTEXTOOL_PATH`.

> **Примечание:** Если у вас нет PVRTexToolCLI, конвертация текстур с KTX-сжатием будет пропущена.

- **Оперативная память:** Конвертация больших файлов (например, `ui.sc` из последних версий игры) может потребовать до **8 ГБ ОЗУ**.

---

## Установка и запуск

1. **Скачайте** последнюю версию `sc2fla.jar` из релизов (или соберите самостоятельно, см. раздел «Сборка»).
2. **Убедитесь**, что `PVRTexToolCLI` доступен (см. выше).
3. Запустите конвертацию из командной строки:

   ```bash
   java -jar sc2fla.jar -d <путь_к_файлу.sc> [-l <лог_файл.txt>] [-t <N|all>]
   ```
   
   Параметры в квадратных скобках `[]` являются **необязательными**.
   
### Параметры

| Параметр | Описание |
| :--- | :--- |
| `-d <файл>` | **Обязательный.** Путь к `.sc`-файлу, который нужно конвертировать. |
| `-l <файл>` | Сохранять весь вывод консоли (информация, предупреждения, ошибки) в указанный текстовый файл. |
| `-t <N\|all>` | Количество потоков для параллельной обработки KTX-текстур. По умолчанию (`all`) – используются все доступные ядра процессора. Укажите число, чтобы ограничить нагрузку. |
| `-h` или `--help` | Показать справку по использованию. |

### Примеры

```bash
# Базовая конвертация
java -jar sc2fla.jar -d assets/ui.sc

# С сохранением лога и использованием 4 потоков
java -jar sc2fla.jar -d assets/ui.sc -l conversion.log -t 4
```

После успешного выполнения рядом с исходным файлом появится файл с тем же именем, но с расширением `.fla` (например, `assets/ui.fla`).

### Что происходит внутри?

Программа выполняет следующие шаги:

Загрузка .sc – распаковывается сжатый контейнер (LZMA или Zstd), читаются метаданные (экспорты, матричные банки, текстуры, фигуры, мувиклипы). 

Предварительная конвертация текстур – все сжатые текстуры (KTX) преобразуются в PNG с помощью PVRTexTool. Конвертация выполняется параллельно в несколько потоков (задаётся параметром -t), что значительно ускоряет процесс. Готовые PNG-изображения хранятся в кэше в памяти.

Обработка фигур (Shape) – каждая фигура разбивается на команды рисования с текстурой. Для каждой команды вычисляется уникальный набор UV-координат, по которому из текстуры вырезается фрагмент (sub‑image). Если фрагмент имеет размер 1×1 пиксель, он заменяется сплошной заливкой (SolidColor). Иначе создаётся отдельный DOMBitmapItem в библиотеке XFL, и PNG‑фрагмент сохраняется в память для последующей записи в ZIP.

Обработка мувиклипов (MovieClip) – создаются слои (по одному на каждого дочернего объекта), кадры с элементами (экземплярами символов или фигур). Для каждого элемента применяются матрицы трансформации и цветокоррекция.

Построение XFL-документа – формируется DOMDocument.xml, библиотечные символы (каждый в отдельном XML-файле), ресурсы (PNG и DAT-файлы для текстур), кеш зависимостей (SymDepend.cache). Все XML-файлы сжимаются с максимальной степенью сжатия (уровень 9) для уменьшения размера итогового .fla.

Упаковка в .fla – все файлы архивируются в .fla. Важно: PNG-файлы сохраняются без сжатия (метод STORED), так как они уже сжаты и повторное сжатие не даст разницы, а только замедлит процесс. Все временные данные хранятся в памяти; временные папки на диске не создаются, что ускоряет работу и снижает нагрузку на диск.

### Сборка из исходников

Для сборки проекта вам потребуется:
* **JDK 17** или новее.
* **Apache Maven** (версия 3.6+).

Клонируйте репозиторий и выполните:

```bash
git clone https://github.com/Invoker4k/sc2fla-java-edition.git
cd sc2fla-java-edition
mvn clean package
```

В папке `target/` появится исполняемый JAR-файл с именем `sc2fla.jar`.
