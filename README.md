# Sc2fla-java-edition
Java converter for SC files to FLA (Adobe Animate project)

The following libraries are used, they are licensed under the MIT License : 
https://github.com/danila-schelkov/sc-file
https://github.com/danila-schelkov/supercell-swf

To run the program, you need PVRTexToolCLI.exe (on Windows) or PVRTexToolCLI (on Linux) in the folder containing the .jar file.
